FiscalWatch is a Windows desktop research application. This static GitHub Pages companion publishes the evidence pack and open-source work. It collects no visitor information and has no remote research database.

From audit recommendation to accountable action

Magnexis Government Fiscal Accountability Initiative begins with a United States evidence register and a Connecticut spending pilot. Its first mission is to independently verify $100 million in potential annual savings. The current verified amount is $0.

The portable build is unsigned and requires Microsoft Edge WebView2. It is a research pilot. Windows is the only packaged and tested build target; macOS and Linux builds are not provided.

Local-first tools

The desktop app has a source-linked recommendation inspector, Connecticut payment and federal award workbench, refreshable official extracts, local SQLite working notes, export/import, a policy comparison basket that blocks overlapping alternatives, and an evidence-based follow-up ledger.
