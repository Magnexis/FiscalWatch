# Contributing

Prefer targeted improvements and reproducible evidence. Include source URLs, publication/status dates, estimate windows, costs, distributional effects and overlaps for fiscal changes. Never add a source estimate to verified savings without independent review and a current baseline.

For code changes run the README checks. Add behavioral regression tests for money, import validation, identity, persistence and source-contract changes. Keep the browser preview and native persistence distinctions explicit. No telemetry or paid service should become mandatory.

Regenerate reports after modifying evidence or bundled data. Include dated corrections in CHANGELOG.md. Avoid uploading invoice personal data, unverified allegations, correspondence, tokens or addresses. Public issues are for software and research corrections, not confidential reports.
